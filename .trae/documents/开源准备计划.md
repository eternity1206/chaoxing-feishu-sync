# 项目开源准备计划

## 当前状态分析

项目功能完整，README 和 GitHub Actions 配置已就绪，但存在以下开源阻碍：

### 严重问题：硬编码凭据泄露
`config.py` 中包含真实的个人敏感信息，直接开源会导致凭据泄露：
- 手机号：`17807131200`
- 密码：`12345678910pxz.`
- 飞书 App ID / App Secret
- 飞书多维表格 token / table_id

### 其他问题
- 缺少 `.gitignore`（`__pycache__`、CSV 导出文件等不应提交）
- 缺少 `.env` 配置方案（应使用 `python-dotenv` 或仅依赖环境变量）
- 调试脚本（`debug.py`、`check_tables.py` 等）包含硬编码 token
- README 中多维表格字段类型说明与实际不符
- 缺少 `LICENSE` 文件
- 缺少 `config.example.py` 示例配置

---

## 实施步骤

### 第 1 步：清理 `config.py` —— 移除所有硬编码凭据

将 `config.py` 改为纯环境变量驱动，不再有默认值泄露：

```python
import os

CHAOXING_USERNAME = os.environ.get("CHAOXING_USERNAME", "")
CHAOXING_PASSWORD = os.environ.get("CHAOXING_PASSWORD", "")
CHAOXING_COOKIE = os.environ.get("CHAOXING_COOKIE", "")
FEISHU_APP_ID = os.environ.get("FEISHU_APP_ID", "")
FEISHU_APP_SECRET = os.environ.get("FEISHU_APP_SECRET", "")
FEISHU_APP_TOKEN = os.environ.get("FEISHU_APP_TOKEN", "")
FEISHU_TABLE_ID = os.environ.get("FEISHU_TABLE_ID", "")
```

## 注意事项

- `__pycache__` 目录也不应提交，通过 `.gitignore` 处理
- `fetcher.py` 中的 `_get_default_courses()` 包含硬编码的课程 ID，这是硬编码的课程 ID（不含个人敏感信息），但建议移除或注释掉，因为这些课程 ID 与其他用户无关，保留会导致他人使用时产生混淆
- Git 仓库尚未初始化，所有文件操作完成后需要 `git init` 并做首次提交
